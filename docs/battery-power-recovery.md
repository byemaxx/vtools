# 间歇性 --W 修复

无线 ADB 现场确认 USB／无线充电均未接入，系统仍报告有效电压（3993mV）。此前接收器对所有电源、开机、低电量事件直接读取电压，缺少 EXTRA_VOLTAGE 时默认 0，覆盖有效缓存；随后功率计算会返回 --W。该缺陷不依赖 ADB 连接方式；未直接捕获修复前应用内存中的电压，不能将所有无效读数都归因于此。

- 非 ACTION_BATTERY_CHANGED 事件从系统粘性电池广播取完整状态，事件分发仍使用原始事件。
- 缺失／无效电压不覆盖有效值，缺失温度和无效容量也不覆盖缓存。
- 功率格式化遇到无效缓存电压时，从粘性电池广播重读，最多每 5 秒尝试一次，不启用额外轮询线程，不用 0W 冒充有效读数。
- 电流不可用时仍显示 --W；保留电流方向、单位和双电芯系数设置。

调试构建、已有 BatteryPowerMathTest 和安全／位置回归通过。通过无线 ADB 安装提交前的 r1807，mini bar 实测恢复显示 -4.30W。仅验证当前设备短时显示，未完成长期运行或反复充电插拔验证。现场证据保存在本地忽略的 build/power-*。
