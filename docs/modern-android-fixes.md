# Android 兼容性修复（2026-10-18）

范围：事件任务执行、异常处理、文件选择、无障碍订阅、页面异步任务、内部广播及应用内网络策略。不提高 targetSdk，不执行设备上的自定义 root 动作，不改用户的系统无障碍开关。

## 已修复

| 问题 | 修改后的行为 |
| --- | --- |
| 事件任务排队后被禁用仍可能执行 | WorkManager 执行时重新加载任务，检查 enabled、事件类型和当前时间段。跨午夜时间段保留原语义；一条不符合条件的任务不阻断其他任务。 |
| 后台直接启动事件服务 | 事件任务、等待息屏后继续的定时任务改用已有 WorkManager。系统可能推迟执行；不自动重试失败的 root 动作。原精准闹钟的服务入口和权限检查保留。 |
| root 动作异常后持有唤醒锁 | shell 清理、通知清理和唤醒锁释放进入 finally。 |
| 崩溃时关闭无障碍并 root 强制结束应用 | 保存私有崩溃日志，再交还 Android 默认异常处理。删除旧的“异常时强退”设置，旧偏好不再生效。 |
| 共享目录错误日志及设置页 root 抓取日志 | 新日志保存于 files/crash/error.log，UTF-8 追加；设置页只读取最近 256 KiB，在后台读取，不自动上传。历史共享目录文件不自动删除。 |
| 本地插件用旧存储权限阻止系统选文件 | 系统文档选择不依赖全盘读写权限；root 路径与文件夹仍使用原有内置选择器。root 自动授予权限流程也跳过 Android 10 以上的旧读写权限。 |
| 文档复制忽略实际读取长度 | 共享解析器改为准确复制、关闭流、检查剩余空间，失败删除不完整副本。无法取得可读原文件的 content URI 导入私有缓存，不依赖 `_data`。 |
| 云文档复制阻塞页面 | 本地插件、在线插件、CPU 配置与镜像选择页在后台解析文件，页面退出后不再继续更新视图。没有通过实际刷写来验证镜像入口。 |
| 无障碍始终请求较宽的事件和节点范围 | 基础只监听窗口事件，合并等待 100 ms；自动安装／跳广告启用后才加入内容事件及节点 ID，等待 50 ms。取消未使用的按键过滤能力；服务销毁时取消补充轮询。 |
| 页面退出后异步任务仍更新 UI | ActivityBase 提供随页面结束取消的协程作用域；相关 Fragment、悬浮窗、场景初始化也使用各自作用域。应用列表、充电能力查询和部分历史查询移至 I/O 线程。 |
| 云端规则更新中途失败丢失旧数据 | 应用级后台作用域不保留 Activity；导入使用数据库事务，失败回滚，关闭数据库与网络输入流。 |
| 内部广播对外开放 | 场景通知、编译状态、固定快捷方式回调三个接收器不再导出；保留应用自己的 PendingIntent 和 root 编译通知生产者。开机接收器只接受声明的两个开机动作。 |
| 快捷启动／冻结操作使用外部字符串拼接 root 命令 | 快捷启动、快捷方式回调和公共冻结／解冻／挂起入口校验包名，拒绝换行、shell 元字符和选项注入。 |
| 全局允许远程明文 HTTP | 应用网络安全配置默认禁止明文，仅放行 localhost 与 127.0.0.1。本项目第一方链接更新为 HTTPS。该配置不约束用户授权执行的独立 root shell 网络命令。 |
| 新版权限回调和旧版任务信息 API | 删除吞掉权限结果的空回调，让框架正常分发；基础页使用兼容 minSdk 的任务 ID 字段；更新触及的 Fragment 非空上下文写法。 |

## 验证

- `scripts/test_modern_android.py`：无危险动作的本地测试，覆盖 root 包名边界、事件时间段／禁用／事件匹配、定时任务边界、调用者身份、私有日志写入、文档字节准确性／空间不足／中断；同时检查广播、网络和无障碍配置。
- 原有电池功率、帧时间、Wh 积分与遥测 SQLite 回归通过。
- 调试构建通过。全仓库 lint 首轮报告 113 个 error；已修复其中本轮涉及的网络属性、权限回调、旧版 API、Fragment 上下文等项目，后一次完整检查降至 58 个 error（主要为旧数据库列索引、资源兼容及旧控件等）。未关闭规则或新增 baseline；完整静态检查不是全绿。

- r1804 已保留数据覆盖安装到 CPH2655 / Android 16。充电、其他设置、耗电统计、FPS 历史页均成功打开；两个可选开关保持关闭，安装前后的系统无障碍列表一致。APK 内三个内部接收器的 exported=false 已核实。

## 边界

- WorkManager 事件处理受系统调度影响，不保证事件发生后立即运行，也不保证进程中断后的非幂等自定义命令只执行一次。
- 未用真实设备操作测试冻结、自动安装点击、刷写、关机或 root 自定义脚本，也未强制制造应用崩溃；没有改变无障碍系统设置来做对照。
- 未验证所有第三方文档提供方、大文件、第三方在线插件、旧安卓设备和所有主题。HTTP-only 在线内容需要改用可信 HTTPS 来源。
- 没有功耗对照测量；减少监听和轮询不等于已证明节省了特定毫瓦数。
